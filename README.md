# 鲁大猿的 AI 学习资料库

> 从一个具体问题出发，理解 AI 的原理，动手验证，再把方法用到新的场景。

你好，我是鲁大猿，在抖音分享 AI 原理、Agent 和 Skills 相关内容。

这个仓库用于沉淀视频配套的详细学习资料。视频里讲清核心问题，文档里进一步展开推导过程、架构与时序、实践示例、异常情况和适用边界，让你看完以后还能查、能复习、能动手试。

资料以 **Markdown、图解和必要的示例代码** 为主。每篇尽量独立成文，即使没有看过对应视频，也能沿着具体案例理解完整机制。

 

## 每篇资料怎样组织

围绕同一个具体案例，尽量走完这条学习路径：

**实际问题 → 基本事实与约束 → 原有办法的局限 → 最小机制 → 逐步推演 → 实践验证 → 适用边界。**

你会在资料中看到：

| 内容 | 帮助你回答的问题 |
| --- | --- |
| 问题与目标 | 为什么需要这项技术，怎样判断问题解决了？ |
| 第一性原理推导 | 原来的办法缺什么，新增机制为什么能起作用？ |
| 最小例子 | 给定一个输入，中间过程和结果分别是什么？ |
| 架构、流程或时序图 | 谁负责什么，信息和动作怎样流动？ |
| 数据、关系、状态或公式 | 内部表示什么，关键约束是什么？ |
| 实践与证据 | 怎样自己验证，哪些结论已经得到支持？ |
| 异常、代价与边界 | 什么情况下会失败，什么时候不值得使用？ |
| 练习与参考答案 | 换一个条件或场景，能否继续推理？ |
| 来源与版本 | 结论依据什么，适用于哪个版本？ |

图的类型按主题选择：有系统协作时画架构与时序，有实体关系时画 ER 图，解释算法时使用计算图、数值推导或曲线。每张图都围绕一个具体问题展开。

## 怎样使用这些资料

**想快速了解一个主题：** 先看开头的问题和一句话结论，再看整体图与最后的复习部分。

**想把机制学明白：** 跟着最小例子逐步推演，观察每一步的输入、变化和输出，再检查结论成立的前提。

**想动手实践：** 阅读示例的环境要求和验证范围，运行后对照预期结果，再修改一个条件观察变化。 

## 内容依据与更新

资料优先参考官方文档、原始论文、源码和可以复现的实践，并在正文或来源章节注明依据。

文档中会区分三类内容：

- **来源支持**：可以在引用资料中查证的事实与机制。
- **教学推演**：为解释问题构造的例子、模型和数据。
- **实际验证**：明确环境和范围下运行得到的结果。

产品与协议会变化，请留意每篇资料的适用版本和更新日期。发现错误时会补充勘误，并说明是否影响结论、图解或示例。
